Folio sur votre appareil

Les applis utilisent le même compte que le site : connectez-vous et retrouvez vos livres, vos notes et vos collections.

Windows

Windows 10 et 11, 64 bits
Comment installer
  1. Lancez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même (l’appli n’est pas encore signée).
  3. Choisissez le dossier d’installation, puis ouvrez Folio depuis le menu Démarrer.

macOS

macOS 13 Ventura ou plus récent
Comment installer
  1. Choisissez Apple Silicon pour un Mac M1, M2, M3 ou plus récent, Intel pour un Mac plus ancien (menu Pomme › À propos de ce Mac).
  2. Ouvrez le fichier .zip et glissez Folio dans le dossier Applications.
  3. L’appli n’est pas encore signée par Apple : avant la première ouverture, collez ces deux commandes dans le Terminal.
xattr -cr /Applications/Folio.app
codesign --force --deep --sign - /Applications/Folio.app

Linux

Debian, Ubuntu, Mint, Kali… (paquet .deb, GTK 4)
Comment installer
  1. Installez le paquet téléchargé avec apt (les dépendances sont ajoutées automatiquement) :
sudo apt install ./Folio-linux.deb
  1. Ouvrez Folio depuis le menu des applications.

Android et iPhone

Depuis le navigateur, sans store
Ouvrir Folio
Comment installer
  1. Android (Chrome) : ouvrez Folio, menu ⋮ › Installer l’application (ou « Ajouter à l’écran d’accueil »).
  2. iPhone / iPad (Safari) : ouvrez Folio, bouton Partager › Sur l’écran d’accueil.
  3. Folio s’ouvre alors en plein écran, comme une appli, et fonctionne hors ligne.

Vous préférez votre propre serveur ? Folio est open source et auto-hébergeable.

Pas envie d’installer quoi que ce soit ? Folio fonctionne aussi directement dans le navigateur.
